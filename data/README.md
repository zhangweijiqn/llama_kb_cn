# 数据目录说明

## 目录作用

`data/` 目录用于存储向量索引和数据文件，这些文件是知识库系统的核心数据。

## 文件类型

### `.index` 文件（FAISS 向量索引）

- **作用**：存储文档的向量索引，用于快速相似度检索
- **格式**：FAISS 二进制格式
- **重要性**：⭐⭐⭐⭐⭐ **非常重要**
- **说明**：
  - 包含所有文档的向量表示
  - 用于快速检索相似文档
  - 重新生成需要重新计算所有文档的向量（耗时）

### `.pkl` 文件（文本和元数据）

- **作用**：存储原始文本内容和文档元数据
- **格式**：Python pickle 格式
- **重要性**：⭐⭐⭐⭐⭐ **非常重要**
- **说明**：
  - 包含文档的原始文本内容
  - 包含文档的元数据（文件名、路径等）
  - 用于在检索后返回原始文本

## 为什么需要这些文件？

### 1. **性能优化**
- 向量计算是耗时操作，每次重新计算需要几分钟到几十分钟
- 保存索引后，后续使用只需几秒钟加载

### 2. **持久化存储**
- 避免每次运行都重新处理文档
- 知识库构建一次，可以长期使用

### 3. **数据完整性**
- 保存了完整的文档内容和元数据
- 即使原始文档被删除，索引仍然可用

## 文件命名规则

文件命名格式：`{index_path}.index` 和 `{index_path}.pkl`

例如：
- `knowledge_base_index.index` + `knowledge_base_index.pkl`
- `test_simple_index.index` + `test_simple_index.pkl`

## 注意事项

1. **不要删除**：除非你想重新构建整个知识库
2. **可以备份**：建议定期备份 `data/` 目录
3. **版本控制**：这些文件通常很大，已添加到 `.gitignore`，不会提交到 Git
4. **磁盘空间**：索引文件可能占用较多空间（取决于文档数量）

## 文件大小参考

- 小型知识库（< 100 文档）：几 KB 到几百 KB
- 中型知识库（100-1000 文档）：几 MB 到几十 MB
- 大型知识库（> 1000 文档）：几十 MB 到几 GB

## 如何管理

### 查看文件
```bash
ls -lh data/
```

### 删除特定索引
```bash
# 删除某个知识库的索引（会强制重新构建）
rm data/knowledge_base_index.index data/knowledge_base_index.pkl
```

### 备份
```bash
# 备份整个数据目录
tar -czf data_backup.tar.gz data/
```

### 清理所有索引
```bash
# 清空所有索引（谨慎操作）
rm data/*.index data/*.pkl
```

## 常见问题

**Q: 可以删除这些文件吗？**  
A: 可以，但删除后需要重新构建知识库，这会花费较长时间。

**Q: 这些文件可以共享吗？**  
A: 可以，但需要注意：
- 确保 Python 版本兼容
- 确保 FAISS 版本兼容
- 确保嵌入模型相同

**Q: 为什么文件这么大？**  
A: 索引文件包含所有文档的向量表示，文档越多，文件越大。

**Q: 可以移动这些文件吗？**  
A: 可以，但需要确保代码中的 `data_dir` 参数指向正确的位置。
