# Web 界面使用指南

## 快速开始

### 1. 安装依赖

确保已安装 Streamlit：

```bash
pip install streamlit
```

或安装所有依赖：

```bash
pip install -r requirements.txt
```

### 2. 启动 Web 应用

```bash
# 方式1: 使用启动脚本（推荐）
./scripts/run_web.sh

# 方式2: 直接运行
streamlit run web_app.py
```

### 3. 访问界面

浏览器会自动打开，如果没有，请手动访问：
- **本地地址**: http://localhost:8501
- **网络地址**: http://你的IP:8501

## 功能说明

### 📄 文档管理标签页

1. **上传文档**
   - 点击文件上传区域
   - 选择要上传的文档（支持多选）
   - 支持格式：TXT、Markdown、PDF、Word (.docx)

2. **查看文件列表**
   - 上传后可以展开查看文件列表
   - 显示文件名和大小

3. **构建知识库**
   - 点击"构建知识库"按钮
   - 系统会自动处理文档并构建向量索引
   - 构建完成后会显示文档片段数量

### 💬 问答标签页

1. **输入问题**
   - 在输入框中输入您的问题
   - 按 Enter 或点击发送

2. **查看答案**
   - 系统会显示生成的答案
   - 可以展开查看参考来源

3. **对话历史**
   - 所有问答都会保存在对话历史中
   - 可以滚动查看之前的对话

4. **参考来源**
   - 点击"参考来源"可以查看：
     - 来源文档名称
     - 相似度分数
     - 相关文本片段

### 📊 统计标签页

查看系统统计信息：
- 文档片段数
- 向量维度
- 索引大小
- 已回答问题数
- 最近对话记录

### ⚙️ 侧边栏功能

1. **初始化系统**
   - 重置系统状态
   - 清空知识库

2. **知识库状态**
   - 查看当前知识库的统计信息

3. **清空对话历史**
   - 清除所有对话记录

4. **使用帮助**
   - 查看使用说明和提示

## 使用流程

### 第一次使用

1. 启动 Web 应用
2. 进入"文档管理"标签页
3. 上传您的文档
4. 点击"构建知识库"
5. 等待构建完成
6. 进入"问答"标签页开始提问

### 日常使用

1. 启动 Web 应用（如果知识库已构建，可直接使用）
2. 进入"问答"标签页
3. 输入问题并查看答案

### 添加新文档

1. 进入"文档管理"标签页
2. 上传新文档
3. 重新构建知识库（会合并新旧文档）

## 常见问题

### Q: 页面无法打开？

A: 
1. 检查是否已启动服务器
2. 确认端口 8501 未被占用
3. 尝试访问 http://localhost:8501

### Q: 上传文件失败？

A:
1. 检查文件格式是否支持
2. 确认文件大小不超过限制
3. 检查文件是否损坏

### Q: 构建知识库很慢？

A:
1. 大文件需要更多时间处理
2. 多个文件会依次处理
3. 首次构建需要生成向量，较慢
4. 后续使用会快很多（使用缓存）

### Q: 答案不准确？

A:
1. 确保文档内容相关
2. 尝试重新构建知识库
3. 检查文档质量
4. 尝试不同的提问方式

### Q: 如何停止服务器？

A: 在终端按 `Ctrl+C`

## 高级功能

### 自定义配置

可以修改 `web_app.py` 中的配置：

```python
# 修改模型配置
st.session_state.qa_system = KnowledgeBaseQA(
    llama_model_name="your-model",  # 使用实际模型
    use_quantization=True
)

# 修改检索参数
result = st.session_state.qa_system.query(
    question,
    top_k=5,  # 增加检索数量
    max_length=1024  # 增加生成长度
)
```

### 部署到服务器

1. **本地网络访问**：
   ```bash
   streamlit run web_app.py --server.address 0.0.0.0
   ```

2. **自定义端口**：
   ```bash
   streamlit run web_app.py --server.port 8080
   ```

3. **生产环境部署**：
   - 使用 Nginx 反向代理
   - 配置 SSL 证书
   - 使用进程管理器（如 systemd、supervisor）

## 性能优化

1. **减少文档大小**：分割大文件
2. **优化 chunk_size**：根据文档类型调整
3. **使用 GPU**：如果有 GPU，系统会自动使用
4. **缓存结果**：相同问题会使用缓存

## 安全提示

1. **本地使用**：默认只允许本地访问
2. **生产环境**：需要配置认证和 HTTPS
3. **文件上传**：注意文件大小限制
4. **数据隐私**：敏感文档请谨慎上传
